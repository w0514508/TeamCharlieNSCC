# 📘 Danielle - Lessons Learned

Throughout this project, several key learnings were identified:

- Data modeling is as important as data analysis; a well-structured schema greatly simplifies calculations and insights  
- Ensuring consistent data granularity (monthly vs yearly) is critical when combining multiple datasets  
- DAX measures require careful handling of filter context to avoid incorrect results  
- Variability and trends should be analyzed separately, as they represent different aspects of data behavior  
- Not all relationships are meaningful — identifying the absence of correlation is also a valuable insight  
- Clear documentation significantly improves the usability and understanding of the model
